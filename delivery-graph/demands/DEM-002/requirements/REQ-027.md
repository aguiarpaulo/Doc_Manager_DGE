# REQ-027

Demand: DEM-002
Priority: must

## Statement

A SPA implementa a arquitetura da base de conhecimento: TypeScript estrito + organizacao por funcionalidade + fronteira HTTP unica e tipada com validacao de resposta + estados explicitos de carga/revalidacao/vazio/erro/sucesso + tokens CSS semanticos + caminho-base configuravel

## Acceptance

- A checagem de tipos passa sem erro e o build falha quando ha erro de tipo
- Nenhum componente chama fetch diretamente; todo acesso remoto passa pela fronteira de dados
- Cada tela de dados distingue visualmente primeira carga / atualizacao em segundo plano / vazio / erro
- Nenhuma cor literal aparece fora dos tokens
- A aplicacao carrega e navega corretamente quando servida sob um subcaminho

## Validation

Method: automated-test

Required evidence:

- Saida da checagem de tipos + regra de lint proibindo fetch fora da fronteira + teste de navegacao sob subcaminho
