# REQ-018

Demand: DEM-002
Priority: must

## Statement

A SPA apresenta a obra no papel de processo: lista de documentos a esquerda em ordem de inclusao crescente + documento selecionado renderizado a direita + barra de acoes no topo + cabecalho identificando usuario e obra

## Acceptance

- Uma obra com 3 documentos os exibe na ordem de inclusao do mais antigo para o mais novo
- Selecionar um documento na lista o renderiza no painel direito sem recarregar a pagina
- A rota reflete obra e documento selecionados de modo que recarregar o navegador restaura a mesma tela
- Uma obra sem documentos mostra estado vazio proprio e nao uma mensagem de erro

## Validation

Method: automated-test

Required evidence:

- Teste de componente com a fronteira HTTP simulada cobrindo ordem / selecao / rota / estado vazio
